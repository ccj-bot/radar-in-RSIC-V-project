# 雷达智脑 2026-11-08 成像与端侧模型实验说明

| 测试模块 | 数值 | 测量范围 |
|---|---:|---|
| YOLO11s 640×640 混合精度纯网络 | 85.4 ms | K3 厂商后端 |
| YOLO11s XSlim INT8 + 浮点解码纯网络 | 40.5 ms | 同设置纯推理，不含 I/O |
| 固定 SAR 文件检测流水线 | 约 22.4 张/秒 | 文件读取、预处理、网络推理和 NMS |
| RDA 软件成像核心 | 41.2 ms | 合成三点、同回波同网格 |
| RVV BP 软件成像核心 | 706.8 ms | 合成三点、同回波同网格 |
| RDA/BP 归一化幅度相关 | 0.99954 | 同场景相干图像对比 |
| 真实 bin 单帧 RD 运算 | 约 4.8 ms | 历史数据回放，非连续采集 |

数据来源：团队正式项目设计报告、项目成果与测试报告，以及本地 K3 优化记录（2026-11-08）。

不可把 22.4 张/秒理解为雷达 ADC 采集、完整 SAR 聚焦、检测、可视化的端到端帧率。17.2× 是 RDA 与 BP 计算核心的受控对照，而非 FPGA 硬件性能相对比。当前未提供独立真实标注集上的 mAP；量化候选一致性验证并非检测精度评测。
